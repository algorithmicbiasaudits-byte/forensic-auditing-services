Definition

What Is a Subprocessor?

A subprocessor is a third-party service provider engaged by ALS Consulting to process data on our behalf. Subprocessors may host infrastructure, deliver notifications, or provide classification capabilities that support the F.A.S. and JD Analyzer platforms.

ALS Consulting remains fully responsible for all data processed by our subprocessors. We conduct due diligence on every provider before engagement and maintain active security and compliance reviews.

Detailed Disclosure

Anthropic (Claude API) — Extended Disclosure

Given the sensitivity of using an AI classification engine to process candidate rejection data, ALS Consulting provides the following detailed disclosure about how Anthropic's Claude API is used within the F.A.S. platform.

How Claude API Is Used in F.A.S.
Structured Classification Only
Role in the Platform
F.A.S. uses the Claude API as a structured classification engine, not a generative decision-maker. The 7 compliance lanes are deterministic, rule-based frameworks with fixed thresholds. Claude parses the rejection payload and maps it to these pre-defined categories.
What Claude Does Not Do
  • Claude does not make final rejection or advancement decisions
  • Claude does not generate the risk score independently
  • Claude outputs are advisory — all flagged decisions require human review
  • The Compliance Officer, not Claude, makes the final determination
  • Escalation logic is determined by ALS proprietary code, not Claude output
Data Handling
  • Candidate data sent to Claude API is hashed and stripped of direct identifiers where possible
  • API inputs are processed in real-time and not retained beyond the session
  • Anthropic's API terms prohibit using API inputs for model training
  • ALS Consulting is actively negotiating a Data Processing Agreement (DPA) with Anthropic
Enterprise Client Options
  • Prompt architecture documentation available upon request
  • Sample audit outputs available for legal review
  • Custom data residency configurations available on Enterprise plans
  • Contact us to discuss AI governance requirements for your jurisdiction

Important: The final risk score, blocking decision, and escalation logic are determined by ALS Consulting's proprietary code — not by Claude's generative output. Every flagged rejection is reviewed and decided by a designated human compliance officer before the candidate is notified. Claude is a classification layer, not a decision-maker.

Data Residency & Transfers

Where Your Data Is Processed

Primary data processing occurs in the United States (Supabase on AWS US-East, Render US regions). For EU-based candidate data, all processing complies with GDPR Article 6 (lawfulness) and Article 21 (individual rights). Data is encrypted at rest (AES-256) and in transit (TLS 1.3).

Where required by client contract or applicable law, data residency restrictions can be configured on Enterprise plans.

US-Based Processing

All primary infrastructure operates in US regions. Supabase (AWS US-East), Render (US), Auth0 (US), Stripe (US), Resend (US).

EU Compliance

EU-based candidate data is processed under GDPR Article 6 (lawfulness of processing) and Article 21 (right to object). Standard Contractual Clauses available on request.

Encryption Standards
  • At rest: AES-256 across all data stores
  • In transit: TLS 1.3 for all API traffic
  • Candidate IDs: hashed before storage
  • Audit exports: encrypted at file level
Enterprise Residency

Enterprise clients may request data residency configurations for specific jurisdictions. Contact us to discuss requirements before contract execution.
